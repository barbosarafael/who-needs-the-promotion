# Experiments

Use this folder for lightweight experiment notes when MLflow alone is not sufficient.

Recommended naming:

```text
EXP-001-logistic-baseline.md
EXP-002-random-forest.md
```

Each experiment should include:

- hypothesis;
- dataset/version;
- split;
- features;
- preprocessing;
- model;
- parameters;
- metrics;
- result;
- interpretation;
- limitations;
- next step.
